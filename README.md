# NumberShop

Telegram-бот для автоматизированной торговли аккаунтами и виртуальными номерами Telegram. Проект предоставляет пользователю каталог доступных номеров, принимает оплату, выдаёт данные для входа и позволяет получить код подтверждения через Telegram-сессию или LZT Market API.

> ⚠️ Используйте проект только в соответствии с законодательством, правилами Telegram и условиями используемых платёжных/API-сервисов. Не применяйте аккаунты для спама, мошенничества, массовой регистрации или других незаконных целей.

## Возможности

### Для покупателей

- просмотр каталога номеров с группировкой по странам;
- отображение цены и замаскированного номера до оплаты;
- оплата в рублях через YooMoney;
- автоматическая проверка платежа по уникальной метке;
- получение номера и кода подтверждения после успешной покупки;
- получение кода через Telethon или LZT Market API;
- раздел «Мои покупки» с историей заказов;
- повторный запрос кода и просмотр информации о покупке;
- канал с отзывами и обращение в поддержку;
- отправка предложений администратору;
- подтверждение правил использования при первом запуске.

### Для администраторов и модераторов

- админ-панель с разграничением ролей;
- добавление номеров в магазин с авторизацией через код Telegram и 2FA;
- покупка лотов на LZT Market по `item_id`;
- изменение цены и удаление товаров;
- выдача компенсационного аккаунта пользователю;
- управление администраторами и модераторами;
- смена LZT API-токена через интерфейс бота;
- уведомления о добавлении товаров и обработка пользовательских предложений.

## Как работает проект

Основная логика находится в `bot.py`:

1. Бот запускается через `AsyncTeleBot` и обрабатывает команды, inline-кнопки и текстовые состояния пользователей.
2. При открытии магазина бот получает доступные товары из БД и группирует их по телефонному коду страны.
3. После выбора товара пользователь создаёт платёж YooMoney. Для платежа формируется уникальная метка, по которой бот проверяет успешную операцию.
4. После подтверждения оплаты товар удаляется из доступного каталога, а покупка сохраняется в истории пользователя.
5. Код входа выдаётся одним из способов:
   - через LZT Market API, если у товара указан `lzt_item_id`;
   - через сохранённую Telethon-сессию, если аккаунт был добавлен напрямую.
6. Flask-приложение параллельно запускает HTTP endpoint для проверки доступности сервиса и webhook YooMoney.

## База данных

Работа с БД реализована в `database.py` с помощью SQLAlchemy. Адрес подключения задаётся переменной `DB_URL` в `config.py`.

Поддерживаются:

- PostgreSQL — основной вариант для размещения на сервере;
- SQLite — резервный вариант, используемый по умолчанию при отсутствии `DB_URL` (`sqlite:///shop.db`).

При запуске вызывается `init_db()`: SQLAlchemy создаёт необходимые таблицы, если они ещё не существуют. Для PostgreSQL URL автоматически приводится к синхронному драйверу `psycopg2`.

### Таблицы

| Таблица | Назначение |
| --- | --- |
| `phone_products` | Каталог номеров: телефон, цена, Telethon-сессия, 2FA, LZT item ID и доступность товара. |
| `purchases` | История покупок пользователей: Telegram ID покупателя, номер, цена, страна и данные для выдачи кода. |
| `admins` | Главные администраторы и модераторы с указанием роли. |
| `settings` | Настройки в формате «ключ-значение», включая LZT API-токен. |

Все операции выполняются через контекстный менеджер `session_scope()`: при успешном завершении выполняется `commit`, при ошибке — `rollback`, после чего сессия закрывается. Номер телефона является уникальным товаром, а доступные товары выбираются по признаку `available = 1`.

## Структура проекта

```text
.
├── bot.py              # Telegram-бот, обработчики, оплата и интеграции
├── database.py         # SQLAlchemy-модели и операции с БД
├── requirements.txt    # зависимости Python
├── config.py           # конфигурация и секреты (создаётся отдельно)
└── shop.db             # SQLite-файл, создаётся автоматически при использовании SQLite
```

## Установка

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/Stepan1604/NumberShop.git
cd NumberShop
python -m venv .venv

# Linux/macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install -r requirements.txt
```

Для PostgreSQL также установите драйвер:

```bash
pip install psycopg2
```

## Конфигурация

Создайте файл `config.py` в корне проекта. Минимальный набор параметров:

```python
BOT_TOKEN = "токен_бота_от_BotFather"
ADMIN_ID = 123456789
ADMINS = [ADMIN_ID]
MODERATORS = []

API_ID = 123456
API_HASH = "ваш_api_hash"
YOOMONEY_WALLET = "номер_кошелька"
DB_URL = "postgresql://user:password@localhost:5432/numbershop"
LZT_API_TOKEN = "токен_lzt_api"
WEBHOOK_PORT = 8080

COUNTRIES = [
    {"code": "RU", "name": "Россия", "flag": "🇷🇺", "phone_code": "+7"},
]
```

Если `DB_URL` не задан, будет использована локальная SQLite-база `shop.db`. Секреты и файл `config.py` не следует публиковать в репозитории.

## Запуск

```bash
python bot.py
```

После запуска бот инициализирует таблицы, загружает роли администраторов, запускает Telegram long polling и Flask-сервис на настроенном порту.

## Зависимости

Проект использует:

- `pyTelegramBotAPI` — взаимодействие с Telegram Bot API;
- `Telethon` — авторизация и работа с Telegram-аккаунтами;
- `SQLAlchemy` — модели и доступ к БД;
- `psycopg2` — подключение к PostgreSQL;
- `aiohttp` и `requests` — HTTP-запросы к YooMoney и LZT Market;
- `Flask` — webhook и health-check endpoint.

## Важно о безопасности

- не храните `BOT_TOKEN`, `API_HASH`, пароли 2FA, Telethon-сессии и API-токены в открытом виде;
- ограничьте доступ к админ-панели и серверу с БД;
- регулярно создавайте резервные копии базы данных;
- перед использованием в production проверьте платёжную логику, права доступа и защиту webhook;
- после входа в приобретённый аккаунт пользователь должен сменить номер, установить 2FA и привязать почту для восстановления.
